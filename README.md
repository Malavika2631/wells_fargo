# Wells Fargo Website Clone

A front-end clone of the Wells Fargo banking website, built with pure HTML and CSS — no frameworks, no JavaScript. Focused on replicating a real-world banking site's page structure and layout.

## Pages

| Page | File |
|---|---|
| Landing page | `index.html` |
| Front/homepage | `front.css` (styling for front page) |
| Additional pages | `page2.html`, `page3.html`, `page4.html`, `page6.html` |

Each page has its own dedicated stylesheet, keeping styling scoped and organized per view rather than relying on one global CSS file.

## Tech Stack

HTML5 · CSS3 — no JavaScript, no frameworks or libraries.

## What this demonstrates

- Recreating a real, complex multi-page banking site layout from scratch
- Structuring a multi-page static site with per-page stylesheets
- Attention to visual detail and layout replication of an existing production website
